UI Convergence × Claude Code

From many legacy UIs to one converged system, in minutes. A Figma-to-code design system for Intuit's Marketing Studio, paired with a Claude workflow that redesigns legacy tool screens against it from a screenshot. How I designed the system, taught Claude to work inside it, and shipped Wave 1.

01 the problem

The product is converged. Its widgets aren't.

Marketing Studio is stitched together from a long tail of legacy tools. Each routes through one of several internal design systems. Each system carries its own themes. Each theme defines hundreds of tokens, plus a "Custom" escape hatch where teams hand-roll hex. The same Button resolves to a different pixel in every tool.

component scale: one button

5 variants × 6 states × 3 sizes × 3 icon placements × 6 themes

= 1,620 permutations ≈ ~1.9 person-years per button

library scale: one library, one theme

54 components × 240 tokens × 48 screens × 18 elements per page

= 11,197,440 mapping points ≈ ~1,120 person-years

Each mapping point is touched by three activities (design and map, publish, QC), each by a designer-developer pair, at roughly 2 minutes per touch. Normalised to 8-hour days, 250 working days a year. This is the surface UI Convergence had to compress.

02 the decision

Three options. One bet.

  1. option 1

    Update existing widget styles in place, by hand

    Sunk cost. Deprecated when V2.0 lands.

  2. option 2 · chosen

    New design system + agent loop (UI Convergence)

    The bridge. Months instead of person-decades. Only affordable because of the agent loop; without it, this collapses back into option 1's cost.

  3. option 3

    Wait for Studio V2.0 (full rewrite, native AI)

    Right destination, not shippable today.

03 what i built

A system, a library, and a loop

  1. figma

    Foundation

    Tokens (color, type, spacing, radius, elevation), components with bound variables and explicit variants, page templates. Authored on demand as new screens surfaced needs.

  2. react

    Library

    A 1:1 implementation in CSS Modules. Every CSS rule resolves to a token. A docs site, a Playground app, and the docs site mirrors the Playground through a shared alias.

  3. skills

    The AI workflow

    Each class of failure became a named, enforceable skill. 17 in total: figma-parity and token-lookup as blocking gates, accuracy-pass and screen-audit as exit checks, playground-compose to orchestrate end to end.

  4. loop

    Screenshot in, production screen out

    Paste a screenshot of a legacy tool. Claude locates the Target State in Figma, inventories components, flags missing ones, composes the screen, and runs the parity audits. The output is a real React screen in the Playground.

04 key decisions

The bets that made the system work

  1. bet 01

    Build the bridge, not the destination

    UI Convergence is deliberately the middle option. It compresses person-decades into months while V2.0 takes the time it needs.

  2. bet 02

    Design the system for an agent, not just humans

    Token names, bound variables, and the Figma-code contract are tightened so Claude can redline against the system by ID, not by visual approximation.

  3. bet 03

    Every recurring failure becomes a skill

    When Claude makes the same mistake twice, write the skill that makes it unreachable. 17 skills, 17 classes of failure.

  4. bet 04

    One source of truth per screen, structurally enforced

    The docs site imports Playground screens through a shared alias. Drift between demo and docs is structurally impossible.

  5. bet 05

    The accuracy bar is the bound Figma variable, measured

    preview_eval reads the computed style. If it diverges from the bound variable, the component isn't done. The bar is what makes the agent loop possible.

05 reality check
wave 1 proved the system works. adoption is the harder half.

Each tool carries its own theme contract. The new components do not drop in. They reconcile against whatever theme the tool already binds to.

Producing a screen is the easy part. Mockup time collapsed. Shipped-pixel time did not.

This is a bridge, by design. When V2.0 lands, today's converged widgets are deprecated. UI Convergence buys months, not forever, and that is the deliberate trade.
